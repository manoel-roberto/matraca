# Matraca

Transforma PDFs em áudio (MP3) com narração em português do Brasil, para estudo de concursos públicos.

> Projeto em desenvolvimento. O README completo (instalação, uso, privacidade, limitações) é entregue na Fase 8.
> Estado atual: veja `docs/STATUS_DO_PROJETO.md`.

## Privacidade (resumo)
O texto do PDF é enviado a um serviço remoto de síntese de voz durante a geração do áudio. É necessária conexão com a internet.
